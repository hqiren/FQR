# FQR 📱

A React Native mobile app built with Expo to help you track your screen time and manage daily goals.

## Features

- 📊 **Screen Time Tracker** — Pie chart visualization of daily app usage
- ✅ **Goals / To-Do List** — Add and remove daily tasks with persistent storage
- 📅 **Date Display** — Shows today's date on the home screen
- 💾 **Persistent Storage** — Tasks saved locally using AsyncStorage

## Tech Stack

- [Expo](https://expo.dev/)
- [React Native](https://reactnative.dev/)
- [Expo Router](https://expo.github.io/router/)
- [react-native-gifted-charts](https://github.com/Abhinandan-Kushwaha/react-native-gifted-charts)
- [AsyncStorage](https://react-native-async-storage.github.io/async-storage/)

## Getting Started

```bash
npm install
npx expo start
```
